# Archiv: frühere Versionen

`alte-versionen/` enthält die Programmstände `commander_db_v6.py` bis `commander_db_v58.py`, wie sie während der
Entwicklung entstanden sind. Was sich in jeder Version geändert hat, steht im Kopf jeder Datei und im
Versionsverlauf unter [`docs/Funktionsvergleich-und-Versionsverlauf.md`](../docs/Funktionsvergleich-und-Versionsverlauf.md).
Aktuell ist immer `server/commander_db.py` bzw. `windows/commander_db_vNN.py`.
